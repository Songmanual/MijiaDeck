Xiaomi Mi Home on Windows 10 / 11

Your Mi Home devices.
Right on your desktop.

Switch a light, check the temperature, preview a compatible camera or send a text command to a XiaoAI speaker. MijiaDeck brings everyday Mi Home controls to Windows and its system tray.

Free & open source · x64 portable ZIP · Unofficial client v1.1.0

DESKTOP CONTROLS

Everyday controls, without reaching for your phone.

01

Device-specific cards

Browse devices by home and room. Toggle supported lights, switch channels and outlets; view channel states on parent panels.

02

Remote camera previews

Compatible cameras have a separate preview window with quality selection, mute, fullscreen and drag-to-pan/tilt. Remote relay access does not require the same LAN. Experimental.

03

XiaoAI speakers in your tray

Select a speaker, adjust volume, play, pause or skip tracks. Send text commands to that speaker without speaking aloud.

04

Compact light controls

Brightness, color temperature and RGB controls appear only where supported. Use the Mi Home mobile app for advanced configuration.

05

Run existing scenes

Execute manual scenes already created in the Mi Home app. MijiaDeck does not create, edit or delete automations.

06

Useful quick-access cards

View supported temperature and humidity readings. Choose and reorder tray cards, select one or two columns and remember the popup position.

Download. Extract. Open.

  1. Download

    Get the Windows x64 ZIP from the latest GitHub release. Choose the application archive, not Source code.

  2. Open

    Extract the complete archive and run MijiaDeck.exe. Keep the _internal folder. No separate Python or Java installation is needed.

  3. Sign in

    Scan the QR code with the Mi Home app. Click the tray icon for quick controls, or right-click it to open the menu.

Capabilities, with clear boundaries.

WindowsWindows 10 1903+ / Windows 11 x64. Windows 7/8 are unsupported. Full Windows 11 hardware testing is still pending.
Switches & readingsLocal hardware feedback exists for multi-channel switches and temperature/humidity readings. Compatibility is not guaranteed across every model in a brand.
CamerasLocal preview feedback exists for a compatible model. Camera transport is experimental and depends on model, firmware and network conditions.
Dimming & colorsThe compact control UI has passed simulated-device interaction tests. More physical-device validation is needed.
Other devicesOnly implemented controls and readouts are offered. Some presence/contact sensors currently show only their name and online state in the main window.
Language & platformsThe application UI is currently primarily Chinese; this website is bilingual. A macOS edition is planned, but is not available yet.
Compatibility records and feedback guide ↗

A few things to know.

Can I control Xiaomi Mi Home devices on Windows without an emulator?
Yes. MijiaDeck is a Windows desktop application. Download the portable ZIP, sign in with the Mi Home app and use the controls supported for your devices.
Can I view a Xiaomi camera remotely from my PC?
Compatible models can open a live preview through a remote relay, without sharing the same LAN. The camera must be online and your network must allow the connection. Not all camera models have been verified.
Can I control XiaoAI speakers with text commands?
Select an online speaker associated with your account, then enter a command. Playback and volume controls target that speaker; they do not change your PC audio output device.
Is this an official Xiaomi Mi Home PC app?
No. MijiaDeck is a free, open-source third-party project with no affiliation to Xiaomi or Mi Home. It focuses on everyday desktop controls, not full mobile-app feature parity.
Does every Mi Home device work?
No. Controls depend on the model, MIoT specification, firmware and account permissions. Devices without implemented quick controls or readouts are omitted from the tray selection list.
How do I upgrade?
Exit the app from its tray menu, then extract the complete new ZIP over the old application directory. Settings and login data are stored in your Windows user profile. Do not replace only the EXE.
