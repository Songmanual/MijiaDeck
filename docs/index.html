桌面控制 / DESKTOP CONTROLS

常用操作，不必再拿起手机。

01

设备卡片直接控制

按家庭和房间查看设备。支持的灯、分路开关和插座可以直接开关，多路面板展示各路状态。

02

摄像头远程查看

兼容米家摄像头可打开独立预览窗口，支持画质切换、静音、全屏和拖动云台；无需处于同一局域网。实验性功能。

03

小爱音箱就在托盘

选择要控制的小爱音箱，播放、暂停、切歌和调音量；输入“打开客厅灯”等文字指令，由所选音箱执行。

04

灯光小控制窗

按设备能力显示亮度、色温、颜色控件。普通灯直接开关，复杂设置仍在米家 APP 中完成。

05

已有场景，一键执行

读取账号中通过米家 APP 创建的手动场景，在电脑上执行。这里不创建、编辑或删除自动化。

06

只留下有用的快捷卡片

温湿度等已支持读数可直接展示。托盘清单按可用控制与读数筛选，支持排序、单列或双列和浮窗位置记忆。

完整解压，就可以开始。

  1. 下载

    从 GitHub 最新发布页下载 Windows x64 ZIP，选择程序包而不是 Source code。

  2. 运行

    完整解压，打开 MijiaDeck.exe。保留 _internal 文件夹，不需要另装 Python 或 Java。

  3. 登录与控制

    用米家 APP 扫码登录，按家庭和房间查看设备；单击托盘图标打开快捷浮窗，右键打开菜单。

支持什么，边界也说清楚。

系统Windows 10 1903+ / Windows 11 x64。Win7、Win8 不支持；Win11 完整实机验证仍待补充。
多路开关、温湿度已有本地实机使用反馈。按设备规格识别分路与读数，不保证同品牌全部型号兼容。
摄像头已有兼容型号实机预览反馈；传输为实验实现，型号、固件和网络都会影响可用性。
调光、色温、调色已实现小控制窗并通过模拟设备交互测试；仍需要更多对应型号的实机验证。
其他设备只显示已支持的操作或读数。部分存在感应、门窗等设备目前仅在主界面展示名称与在线状态。
语言与平台程序界面目前主要为中文；此网站有中英文介绍。macOS 版在计划中，尚无可下载版本。

你可能正想问这些。

Windows 怎么控制米家设备？需要安卓模拟器吗？
MijiaDeck 是 Windows 桌面程序，无需安卓模拟器。下载免安装包并用米家 APP 扫码登录后，可查看设备并操作已适配的功能。
电脑怎么看小米摄像头？能在外网查看吗？
对兼容型号，点击摄像头卡片或播放按钮打开实时预览。支持通过远程中继查看，不要求电脑与摄像头处于同一局域网；摄像头需在线，网络须允许传输。并非所有型号都已验证。
电脑可以给小爱同学发文字指令吗？
可以。选择账号下在线的小爱音箱后输入指令，由该音箱执行。托盘也可控制所选音箱的播放与音量；这不改变电脑的音频输出设备。
这是小米官方的米家电脑版吗？
不是。MijiaDeck 是免费开源的第三方项目，与小米、米家官方没有隶属关系。它聚焦桌面快捷查看和控制，不能替代官方 APP 的全部功能。
所有米家设备都能用吗？
不能保证。可用控制取决于设备型号、MIoT 规格、固件和账号权限。没有已适配快捷控制或读数的设备，不会出现在托盘添加清单中。
更新怎么安装？设置会丢吗？
先从托盘菜单退出，再完整解压新版 ZIP 覆盖旧程序目录。个人配置与登录信息存放在 Windows 用户目录中；不要仅替换 EXE。
