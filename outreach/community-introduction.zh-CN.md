# 不用模拟器，在 Windows 上控制米家、看兼容小米摄像头：MijiaDeck

平时坐在电脑前，想开个灯、看眼温湿度，或者暂停另一间房的小爱音箱，还得拿手机。为了少折腾这一步，我们做了 MijiaDeck，把常用米家操作放到 Windows 桌面和系统托盘里。

项目基于 MiHome-Windows 改进，免费开源，不是小米官方客户端。我们的定位比较简单：电脑上快捷查看、控制和调度，复杂设置继续用米家 APP。

目前能做的事情：

- 按家庭和房间查看设备，直接控制支持的灯、分路开关和插座，查看已适配的温湿度读数。
- 把常用设备和已有手动场景放到托盘浮窗，不必一直开着主界面；浮窗可以拖动并记住位置。
- 在托盘切换要控制的小爱音箱，调音量、播放、暂停、切歌，或者输入文字指令让所选音箱执行。
- 对兼容米家摄像头打开独立预览窗口，查看实时画面、切换画质、全屏，并在支持的型号上拖动云台。不要求电脑与摄像头在同一个局域网。
- 为支持相应属性的灯提供亮度、色温和颜色小控制窗。

摄像头还是实验性功能，不能保证所有型号；灯光小窗目前有模拟设备交互测试，还需要更多实机反馈。存在感应、门窗等设备也没有一概宣称全部支持。具体情况放在兼容性记录里，避免大家下载后才发现预期不一样。

当前支持 Windows 10 1903+ / Windows 11 x64，下载完整 ZIP 解压后运行 MijiaDeck.exe，保留 _internal 文件夹，不需要另装 Python 或 Java。用米家 APP 扫码登录即可。程序界面目前主要为中文，macOS 版还在计划中。
